# Mi_portafolio
Portafolio web profesional y hoja de vida responsiva desarrollada con HTML y CSS.

Sitio web personal que incluye mi hoja de vida profesional y mi portafolio de proyectos de desarrollo de software.

**Sitio publicado:** https://github.com/Mari-Reyes/Mi_portafolio (Repositorio en GitHub)
                     https://mari-reyes.github.io/Mi_portafolio/ (Link de la pagina web)

## Páginas del sitio
* `index.html`: Hoja de vida principal (perfil, formación y habilidades técnicas).
* `proyectos.html`: Portafolio de proyectos desarrollados (CLI, Python, web).
* `contacto.html`: Medios de contacto profesionales y redes técnicas.

## Breakpoints

* **Base (Celular / Mobile First):** El diseño se presenta en una sola columna vertical, con el menú de navegación apilado debajo de la cabecera.
* **Desde 600px:** El diseño ajusta los márgenes y permite una mejor distribución de las tarjetas de habilidades y proyectos.
* **Desde 1024px (Computador):** Se activa la estructura avanzada de CSS Grid con `grid-template-areas`, posicionando el menú a un lado y el contenido principal expandido en varias columnas.

## Cómo lo publiqué
1. Creé un repositorio público en GitHub con el nombre de mi portafolio.
2. Organicé los archivos localmente respetando las minúsculas y rutas relativas.
3. Subí todo el código fuente mediante commits utilizando la terminal de Git.
4. Me dirigí a la pestaña "Settings" del repositorio en GitHub, entré a la sección "Pages", seleccioné la rama `main` (o la rama de despliegue) y la carpeta raíz (`/root`), y guardé los cambios para generar el enlace oficial.
